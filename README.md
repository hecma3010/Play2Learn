# Play2Learn

A front-end website for math-facts practice, built with vanilla JavaScript as a course final project.

## Features

- The player chooses an operation before starting: addition, subtraction, multiplication or division
- Pressing Go shows a random equation and starts a 30-second countdown
- Answers can be entered with the physical keyboard or the on-screen number pad
- Each correct answer adds one point to the score
- Wrong answers carry no penalty; the player keeps trying while the timer runs
- When time runs out, a final screen shows the score and a time's up message
- The home page lists both games, each with a description and a Play button
- A "Happy Clients Say" section rotates testimonials every 10 seconds
- The login page toggles between the login and register forms without reloading
- Forms block empty submissions with required fields and show a confirmation alert on submit, without reloading the page
- Anagram Hunt shows a "coming soon" page; the game will be built in a later stage of the course

## Tech stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Bootstrap 5.x
- Bootstrap Icons 1.x

## Running locally

Double-click or open `index.html` in any modern browser
